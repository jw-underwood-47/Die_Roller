# Die_Roller
Roll dice, with modifiers as desired

### Usage
```./roll_die.exe [number of dice][d]size [+modifier] [+modifier]```
Can do several such rolls in sequence.  For example, 
```./roll_die.exe 4d12 +4 3d8 +1d4```
will roll 4 d12s, add 4 to the result, and then separately roll 3 d8s and add a d4 to the result of that.
